# v2 randomized-multi-source simulated frames (2026-08-14/15)

Supersedes the 275-550cm simulated-distance data that the sibling `analyze_1_6.py`
in this folder reads (`SIM_DIR` -> `exported_charts/1-6/real_video_results_simulated_filtered/`,
all dated 2026-08-06). That older data was generated by `nano_scripts/simulate_far_distance_frames.py`,
which always rescales from ONE fixed nearest real distance per target (e.g. all of
425-550cm sourced from the same 400cm footage) -- confirmed by checking `source_video`
in the old CSVs: every simulated-distance bin traces back to only 3 source videos
(one per n_people group), identical in count to the real 100-400cm bins. This let a
single source video's idiosyncrasies (a 475cm keypoint-mislocalization spike) dominate
an entire simulated-distance bin.

**This v2 pipeline fixes that**: each target simulated distance draws a random sample
of 300 (source_distance, frame_idx) pairs per n_people group, without replacement, from
ALL 7 real source distances (100-400cm) -- see `generate_randomized_simulated_frames.py`.
Each sampled frame is individually rescaled based on its own true capture distance, using
a `shoulder_px(d) = K / (d + offset)` model fit on real 100-400cm data (R^2=0.99946,
`fit_shoulder_px_model.py` / `shoulder_px_model.json`), not synthetic data. `random.seed(42)`
+ `np.random.seed(42)` make the sampling deterministic/reproducible given the same source
videos.

`yolo11x-pose.real_video_v2.csv` is the correction-target reference curve, rerun by
`run_yolo11x_real_video_v2.py` on these SAME v2 simulated frames (the reference curve was
missed on the first pass and had to be rerun separately for the comparison to be internally
consistent -- caught by user review).

## Pipeline order

1. `generate_randomized_simulated_frames.py` -- writes 8100 PNGs (9 target distances x
   3 n_people groups x 300 frames each, confirmed via `frame_manifest.csv`) to a scratch
   output dir (not included here -- see "What's not included" below).
2. `batch_infer_simulated_far_v2.py` -- runs each deployed-model precision variant on
   those frames -> `raw_detections_simulated/sim_*.csv` (6 variants).
3. `run_yolo11x_real_video_v2.py` -- runs yolo11x-pose (FP32 reference) on the same
   frames -> `yolo11x-pose.real_video_v2.csv`.
4. `analyze_v2_simulated.py` -> an intermediate pass.
5. `analyze_v2_fully_consistent.py` -- final pass, reference curve and deployed-variant
   results both rerun on identical v2 frames -> `v2_fully_consistent_results.csv` and
   `1-6-2_R_value_raw_vs_corrected_vs_distance_v2.pdf/png`.

## Verified against the paper (2026-08-15)

`v2_fully_consistent_results.csv`'s per-distance `miss_corrected` mean: max is 9.056%
(fp32, 475cm), all distances under 10% -- matches main.tex IV-C paragraph 5 exactly
("stays under 10% throughout the full 250--550cm range, peaking at 9.1% near 475cm").
`1-6-2_R_value_raw_vs_corrected_vs_distance_v2.pdf` is pixel-identical (verified via
PyMuPDF render + array comparison) to the copy currently in
`journal_paper/figure_assets/figures/main/pdf/1-6-2_R_value_raw_vs_corrected_vs_distance.pdf`
-- the paper is already using this v2 data, not the stale 8/6 version.

## Raw simulated frames

`real_video_frames_simulated_v2.tar.gz` (3.7GB) contains all 8100 actual simulated PNGs
(9 target distances x 3 n_people groups x 300 frames), matching `frame_manifest.csv`.
Extract with `tar -xzf real_video_frames_simulated_v2.tar.gz` -- unpacks to
`real_video_frames_simulated_v2/{n_people}{target_distance}/frame_NNNN_src{source_d}_orig{source_frame_idx}.png`.
They're also regenerable deterministically from `generate_randomized_simulated_frames.py` +
`frame_manifest.csv` + the original `Test_21/*.mp4` source videos (same random seed, 42), if
ever needed without extracting the archive.
